# ARIMA Time-Series Analysis Workshop in R

This repository contains R code and presentation slides for a hands-on workshop on ARIMA time-series analysis.

Using an interrupted time-series example examining changes in opioid prescription claims following a COVID-19 policy in Ontario, we walk through:

1. Creating and visualizing time-series data
2. Checking stationarity using ACF, PACF, and ADF tests
3. Applying differencing
4. Selecting ARIMA models manually and automatically
5. Checking model residuals
6. Estimating intervention effects
7. Comparing models and forecasting future observations

## Materials
- **R-Code:** R scripts used during the workshop
- **Slides:** PowerPoint and PDF presentations

## Software
R and RStudio, using packages such as `forecast`, `tseries`, and `ggplot2`.

## Data
The original administrative healthcare data are not publicly shared. Any example data included here should be synthetic or approved for public release.
